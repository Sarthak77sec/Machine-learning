# 🧠 My Machine Learning Journey

> Learning Machine Learning by building, breaking, fixing, and understanding.

This repository is my personal record of learning Machine Learning.

I'm not trying to make this look like I've already mastered ML.  
Instead, I'm documenting **how I'm actually getting there** — the concepts I'm learning, the experiments I'm running, the mistakes I make, and the things that finally start making sense.

Some notebooks may be messy. Some experiments may fail.

That's intentional.

Because this repository is about **the learning process**, not just the final result.
